# Evaluation Rubric

Use this rubric for daily checks and phase assessments. Evaluate demonstrated performance, not confidence alone. The rubric supports learning decisions; it is not an official CEFR examination.

## Daily check

Score each category from 0 to 2.

| Category | 0 — Not demonstrated | 1 — Partial | 2 — Demonstrated |
|---|---|---|---|
| Comprehension | Cannot identify the main meaning | Understands the gist with help | Understands the main point and key details |
| Vocabulary | Cannot retrieve target phrases | Retrieves some with prompts | Retrieves and uses phrases in context |
| Spoken production | Cannot complete the task | Completes with substantial support | Completes understandably with limited support |
| Interaction | Cannot respond or clarify | Responds but struggles to continue | Responds, asks follow-up questions, or repairs confusion |
| Evidence | No practice evidence | Partial evidence | Practice and answers are recorded |

**Suggested pass:** 8/10 or higher, with no zero in spoken production when speaking is the main objective. The oral task must be attempted. When a lesson includes listening comprehension as an assessed objective, listening must actually be performed; reading a transcript aloud is not listening evidence.

## Phase assessment

Each phase assessment uses the fixed task weights shown in the phase-assessments document, which total exactly 100 points. Do not change task weights after seeing the results.

Include evidence of:

1. A listening task suitable for the phase.
2. A spontaneous speaking task.
3. A role-play or dialogue.
4. Retrieval of target phrases without reading.
5. A short reflection on errors and next steps.

**Suggested phase pass:** at least 80/100, with all required tasks assessed and the main message understandable. If any required task is missing, mark the checkpoint **Incomplete** rather than passing it based on a partial score. If the score is below 80 or an essential skill is unreliable, mark **Review**, identify the skill to practise, and repeat a similar task later.

Record the task, actual score, date, evidence, and corrections in the relevant daily log. Do not claim a CEFR level from this internal rubric alone.

## Status definitions

- **Pending:** not started.
- **In progress:** started but evidence is not yet complete.
- **Review:** attempted, but the pass criteria were not met or a key skill needs more practice.
- **Approved:** required work and evidence are complete, and the relevant pass criteria are met.
- **Incomplete / Not assessed:** a required task was not performed or there is not enough evidence to score it fairly.

Do not mark a lesson or phase approved only because the file was opened, the exercise was read, or the scheduled day has passed. Do not invent scores or claim listening performance that did not happen.

## Feedback format

- **What worked:** specific example from the learner's actual response.
- **Correction:** original phrase → corrected phrase.
- **Why:** brief explanation in Spanish.
- **Retry:** a similar prompt to verify learning.
- **Decision:** Approved / Review / Incomplete.

Do not mark a session approved without evidence that the required speaking and, when applicable, listening tasks were attempted.
