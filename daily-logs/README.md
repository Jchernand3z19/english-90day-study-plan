# Daily Study Logs

Create one file per session using the naming pattern day-001.md, day-002.md, and so on.

Copy this template into the new file. Keep the result as **Pendiente** until the exercises and evaluation have been completed.

- Speaking task:
- Example sentences produced:

## Evaluation
- Score:

- Review needed:
- Next session:

A log should describe what actually happened. Do not invent durations, scores, recordings, or completed activities. If no audio recording was made, describe the oral task instead of claiming a recording exists.
