## Guidelines

- Record real errors from lessons, speaking practice, or assessments.
- Keep explanations short and understandable.
- Revisit open errors during Anki review or the next related lesson.
- Do not treat every small mistake as a failure; prioritize errors that change meaning or repeatedly block communication.
- Mark a correction as learned only after using it correctly again without looking.
