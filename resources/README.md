# Study Resources — Start Here

This page tells you **which resource to open for each kind of practice**. The daily lesson is the task list; this page is the resource directory.

## 1. Speaking and conversation practice

**Resource:** ChatGPT as your conversation tutor (this chat is fine).

At the start of a session, paste this instruction:

> Act as my patient English conversation tutor. My level is approximately A1/A2. Follow today's lesson from the English 90-Day Study Plan. Explain difficult points in Spanish, then practise in English. Ask one question at a time and wait for my answer. Do not show me a complete answer before I try. Prioritise conversation, useful listening, and pronunciation over isolated grammar exercises. Correct only one or two important errors at a time, ask me to try again, and do not mark the lesson passed without evidence.

For a role-play, tell the tutor the situation (for example, ordering food or checking into a hotel). Answer aloud if using voice; do not count silently reading a script as speaking practice.

## 2. Listening practice with real audio

**Alignment rule:** these are resource libraries, not yet a verified day-by-day match. Do not assume any random A1/A2 activity matches the lesson. For each lesson, select an audio whose situation and target phrases match that day's objective, and record the direct activity link in the lesson. Until that mapping is done, use these directories only as a fallback and ask the tutor to confirm the fit before counting the activity as completed.

Use these free, level-labelled resources. Open the lesson and play the recording; do not read the transcript first.

- **A1 listening — British Council LearnEnglish:** https://learnenglish.britishcouncil.org/free-resources/listening/a1
- **A2 listening — British Council LearnEnglish:** https://learnenglish.britishcouncil.org/free-resources/listening/a2
- **A1–A2 listening and pronunciation activities — Cambridge English:** https://www.cambridgeenglish.org/learning-english/activities-for-learners/

### How to use an audio lesson
1. Read only the title and preparation task.
2. Listen once without opening the transcript.
3. Answer the questions or note the main idea.
4. Listen a second time.
5. Open the transcript and compare it with what you heard.
6. Replay a short section and repeat it aloud, copying the rhythm.
7. Record whether you actually listened and how many questions you answered correctly.

Choose A1 material at the beginning. Move to A2 only when the current material is understandable enough to practise actively. If the daily lesson includes its own script, the tutor can read it aloud without showing it first; a real audio recording is preferable when available.

## 3. Anki — spaced phrase review

**Purpose:** review useful English phrases for 10 minutes, trying to recall the English before revealing the answer.

- Official Anki website: https://apps.ankiweb.net/
- Anki shared-deck directory: https://ankiweb.net/shared/decks

**Important status:** this repository currently has an Anki progress tracker for a target of 1,000 phrases, but it does **not** contain the deck file or a verified link to a specific 1,000-phrase deck. Do not assume that the deck is already installed or count cards until the actual deck is selected and checked. A shared deck is supplementary material; use phrases you understand in context, not memorisation alone.

When choosing a deck, check that it has English phrases, useful meanings or examples, and audio if available. If a deck is not suitable, leave Anki progress at zero rather than pretending it is set up.

## 4. Pronunciation and shadowing

Use a short section of the audio resource in section 2. Listen to one sentence, pause, repeat it aloud, and compare the rhythm and stressed words. Practise a few sentences rather than repeating a long passage mechanically.

## 5. What to open for each daily lesson

| If the lesson asks you to… | Open/use this |
|---|---|
| Review phrases | Anki, once the deck is selected and installed |
| Listen and answer questions | The audio link specified by the lesson, or the A1/A2 listening directory above |
| Shadow a dialogue | The same audio; listen first, then repeat short sections |
| Answer questions or role-play | ChatGPT conversation tutor; answer aloud when possible |
| Check your progress | `tracker.md`, the lesson's self-check, and the evaluation rubric |
| Record mistakes | The daily log and error log; record only what actually happened |
