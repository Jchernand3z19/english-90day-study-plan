# Índice diario de recursos gratuitos (90 días)

**Objetivo:** que cada lección tenga una ruta clara para practicar escucha, conversación, pronunciación y lenguaje funcional sin buscar recursos al azar. La lección interna sigue siendo la actividad principal. Los enlaces de catálogo no se presentan como una actividad específica ya seleccionada.

## Cómo interpretar la guía

- **Actividad directa:** enlace a una actividad concreta; úsala sólo si el tema coincide.
- **Catálogo:** elige una actividad cuyo tema y dificultad encajen; si no encuentras una coincidencia, no fuerces el enlace.
- **Práctica interna:** usa el diálogo y el role-play de la lección con el tutor. Para evaluar escucha, el tutor debe leer el diálogo sin mostrarlo primero o debes escuchar audio real.
- Todos los recursos enlazados son gratuitos. No necesitas crear una cuenta para usar los materiales principales de British Council. Algunas series de BBC pueden ser demasiado avanzadas: no las uses sólo por ser populares.

## Reglas para mantener la calidad

1. No usar una actividad sólo porque sea gratuita o del mismo nivel; debe coincidir con el tema.
2. No contar leer una transcripción como evidencia de comprensión auditiva.
3. No presentar los catálogos como si cada enlace fuera una actividad específica seleccionada.
4. La práctica oral y el role-play de cada lección siguen siendo centrales.
5. No hay recurso externo único para cada uno de los 90 días; cuando no exista una coincidencia verificada, se declara el límite y se usa la actividad interna.
6. Anki queda fuera de este trabajo: el mazo existente se ordenará cuando el usuario lo comparta.
